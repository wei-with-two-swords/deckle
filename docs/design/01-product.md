# Deckle 产品设计（v0.1）

> 状态：设计基线，M0 产物。实现与本文冲突时，先改文档再改代码。

## 1. 一句话定位

Deckle 是一款**离线、桌面优先的 Typst 论文编辑器**：左边写 `.typ` 源码，右边实时看到排版结果，错误就地提示，一键导出 PDF。界面语言与交互参照 typst.app 的项目页，但完全本地运行，不需要账号。

## 2. 目标用户与场景

| 用户          | 场景               | 关键诉求                               |
| ------------- | ------------------ | -------------------------------------- |
| 本科生/研究生 | 课程论文、毕业论文 | 模板简单、中文正常、公式好写、导出 PDF |
| 科研人员      | 会议/期刊投稿      | 多文件工程、参考文献、精确排版、编译快 |
| Typst 初学者  | 从 Word/LaTeX 迁移 | 实时预览、错误提示、示例模板           |
| 教师          | 讲义/试卷          | 离线、可打印、公式与表格               |

v0.1 只服务**单机、单用户**，不做账号、登录、成员、权限、评论、分享或云同步；所有项目与数据只在本机。团队协作、云端同步、在线发布不在范围内。

## 3. 产品原则

1. **源码即真相**：编辑器始终展示 `.typ` 源码，不做隐藏语法的 WYSIWYG。
2. **单用户、无账号**：没有登录、成员、权限、邀请或分享；应用不知道自己“是谁”。
3. **即时反馈**：输入到预览的延迟目标 < 300ms（10 页文档）。
4. **错误不打断**：编译失败保留上一次成功预览，错误集中到 Issues 面板。
5. **本地优先**：项目就是普通文件夹，用户可用 Git/网盘自行管理；应用数据只在 `userData`。
6. **视觉克制**：界面 chrome 退到背景，纸面是主角；颜色只用于状态与操作。
7. **可替换的视觉层**：所有颜色/尺寸集中在设计变量，换皮不影响逻辑。

## 4. 范围

### 4.1 v0.1（MVP）

**项目**

- 新建项目（选择父目录 + 名称 + 空白模板）。
- 打开项目（含 `.deckle/project.json`）或普通文件夹（自动识别 `main.typ`）。
- 最近项目列表（SQLite），可移除、可定位丢失项目。
- 单实例；再次打开应用时聚焦已有窗口。

**文件**

- 文件树：展开/折叠、键盘导航、新建文件/文件夹、重命名、删除、刷新、在资源管理器中显示。
- 快速打开（Ctrl+P，按文件名模糊匹配）。
- 面包屑：`项目 / 相对路径 / 文件名`。

**编辑**

- CodeMirror 6：Typst 语法高亮、括号匹配、自动补全、查找替换。
- 格式化工具栏：粗体、斜体、下划线、标题级别、无序/有序列表、数学、代码块、引用（引用标签为 P1）。
- 每文件独立撤销栈；切换文件不丢未保存内容。
- 自动保存（800ms 空闲）；手动保存 Ctrl+S；保存失败保留脏状态并提示。
- 外部修改检测：干净时自动重载；脏时冲突对话框。

**编译与预览**

- 200ms 防抖；同一项目串行编译，最新请求优先。
- 多文件工程；未保存缓冲区通过 shadow 映射参与编译。
- 多页 canvas 预览、缩放 50%–400%、适应宽度、页码/页数。
- 编译 spinner、耗时、错误/警告计数。
- 诊断列表（文件、行、列、级别、消息），点击跳转；编辑器行内标记。
- 预览区滚动与缩放；页面按视口懒渲染。

**导出**

- 导出 PDF（默认标准），保存对话框；导出成功后可打开所在文件夹。

**外观与窗口**

- 明/暗主题（手动切换，持久化）。
- 无边框窗口、自定义标题栏、最小化/最大化/关闭、双击标题栏最大化。
- 左侧面板折叠（Ctrl+B）、分隔条拖拽、布局持久化。
- 设置弹窗：主题、编辑器字号/缩进/自动保存、预览默认缩放、关闭行为。

**质量**

- 中文界面；中文文档编译与 PDF 嵌入正常。
- 崩溃后可从快照恢复未保存内容（M6 完整 UI，M4 落数据）。
- Windows 安装包可安装/卸载；macOS/Linux 至少可打包运行。

### 4.2 P1（v0.2 及以后）

- 多标签页 / 打开编辑器列表。
- 项目全文搜索（替换）。
- 快照历史 UI 与一键恢复。
- 模板库（空白、论文、简历、讲义）。
- 本地 BibTeX / CSL 文献导入（不做 Zotero/Mendeley 同步）。
- 打印、导出 PNG/SVG、PDF 标准选项（PDF/A、PDF/UA）。
- 本地包管理（`@preview` 包缓存与离线安装）。
- 自动更新、`.typ` 文件关联、最近文件跳转。
- macOS 原生交通灯与 Linux 桌面集成。
- 拼写检查、中文输入法优化、无障碍增强。

### 4.3 明确不做

- 账号、登录、成员/权限、订阅、云同步、在线协作、评论、发布/分享链接、Git 集成（用户自行用外部 Git）。
- AI 续写/润色。
- 移动端、Web 版。
- 在线模板市场、社区包市场。
- 与 typst.app 的数据互通。

### 5.1 页面模型

应用只有两个顶层页面，导航与设置一律按“当前页面”区分：

1. **Dashboard（无打开项目）**：应用启动后的默认页，展示最近项目与新建/打开入口。左侧 rail 只保留“应用设置”与自有字标；没有项目工具。这里打开的设置是**应用设置**（主题、关闭行为、字体目录、关于）。
2. **项目页（打开一个项目）**：同一时间只打开一个项目；rail 切换为项目工具（文件、搜索、大纲、问题）与“项目设置”。topbar 中间面包屑实时显示 `Dashboard › 项目名 › 打开的文件`，点击 `Dashboard` 或左上返回箭头回到 Dashboard。这里打开的设置是**项目设置**（项目名称、主文件、路径），不修改应用级配置。

返回 Dashboard 时保存当前 workspace 并关闭项目；重开项目时恢复面板宽度、编辑/预览比例、缩放与上次打开的文件。应用级设置与项目级设置不混用，避免“在项目里改了全局主题/字体”这类跨项目副作用。

## 6. 关键用户流程

### 6.1 首次启动

1. 显示欢迎页：左侧 rail + 最近项目网格 + “新建项目”。
2. 新建项目：输入名称、选择父目录 → 创建 `<parent>/<name>/`、`.deckle/project.json`、`main.typ`（含示例段落与公式）。
3. 自动打开项目，选中 `main.typ`，预览在 1.5s 内出现。

### 6.2 日常编辑

1. 打开最近项目 → 恢复上次文件、面板宽度、缩放、滚动位置。
2. 输入 → 200ms 后编译 → 预览更新；错误时红 pill 增加，Issues 面板可点。
3. Ctrl+S 或 800ms 空闲自动保存；topbar 显示 `Saving… → Saved`。
4. 关闭窗口时若有未保存内容，先 flush；失败则询问。

### 6.3 导出

1. Ctrl+Shift+E 或预览 toolbar 的导出按钮。
2. 保存对话框默认文件名 = 项目名.pdf；导出成功 toast，可“打开所在文件夹”。

### 6.4 异常

- 项目被移动：最近项目置灰，点击提示“重新定位”。
- 外部编辑冲突：对话框三选一（重新载入磁盘版本 / 覆盖保存 / 取消）。
- 编译错误：旧预览保留，错误列表更新，状态 pill 变红。
- 崩溃重启：检测到快照，提示恢复（P1 完整 UI，M4 起记录）。

## 8. 术语

| 术语                     | 含义                                                                                      |
| ------------------------ | ----------------------------------------------------------------------------------------- |
| 设计变量（design token） | 颜色、字号、间距、圆角、阴影等命名常量；集中在 `tokens.css/tokens.ts`，**不是模型 token** |
| 项目（project）          | 含 `.deckle/project.json` 的文件夹；普通文件夹打开时自动识别                              |
| 主文件（main file）      | 编译入口，默认 `main.typ`，可在 project.json 修改                                         |
| 缓冲区（buffer）         | 编辑器内存中的文件内容，可能尚未落盘                                                      |
| shadow                   | typst.ts 的虚拟文件映射，让未保存内容参与编译                                             |
| vector artifact          | 编译器输出的矢量排版产物，供 WASM 渲染器绘制                                              |
| sheet                    | 编辑/预览面板里带阴影的白色纸面容器                                                       |
| rail                     | 最左侧 64px 图标导航轨                                                                    |
| topbar                   | 顶部 40px 自定义标题栏（菜单/面包屑/状态/窗口按钮）                                       |

## 9. 法律与品牌

- Deckle 是独立项目，**与 Typst GmbH 无关联**；关于页与 NOTICE 中声明。
- 不使用 Typst 的名称作为产品名、不使用其 logo/字标；图标全部自绘或使用 ISC/MIT 许可的通用图标；不逐字节复制 typst.app 的 SVG 路径或 CSS/JS 资源。界面布局与设计变量作为视觉参考，代码与资产均为独立实现。
- 界面布局与颜色数值作为设计参考；不复制 typst.app 的 CSS/JS/HTML 源码，不逐字节复制其 SVG path。
- 依赖许可：Typst/typst.ts（Apache-2.0）、CodeMirror（MIT）、React（MIT）、MUI（MIT）、lucide（ISC）。界面使用系统字体，不随包分发字体资产。安装包内附 `THIRD_PARTY_NOTICES.md`。

## 10. 成功指标（上线后）

- 首次打开到可编辑 < 3 次点击。
- 冷启动到欢迎页可交互 < 2s。
- 崩溃率 < 0.5% 会话。
- 预览延迟投诉为 0（p95 达标）。
- 不收集任何遥测/账号数据；默认完全离线。
