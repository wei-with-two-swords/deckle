## 2. 字体与排版

| 用途        | 字体栈                                                                          | 字号/行高     | 字重            |
| ----------- | ------------------------------------------------------------------------------- | ------------- | --------------- |
| UI 正文     | `Inter, "Segoe UI", "Microsoft YaHei", sans-serif`                              | 13px / 1.45   | 400             |
| 菜单/按钮   | 同上                                                                            | 13px / 1      | 600             |
| 面板标题    | 同上                                                                            | 16px / 1.3    | 600             |
| 状态 pill   | 同上                                                                            | 11px / 1      | 600，大写       |
| 代码/编辑器 | `"Cascadia Mono", "Cascadia Code", Consolas, "Microsoft YaHei Mono", monospace` | 13px / 18.2px | 400             |
| 面包屑      | 同上 UI                                                                         | 13px / 1      | 400，文件名 700 |
| 提示/空状态 | 同上 UI                                                                         | 12px / 1.5    | 400             |

- 字体不随包分发：UI 优先系统 `Inter`，缺失时回退 Segoe UI / 微软雅黑；等宽字体优先系统 `Cascadia Mono`（Windows 自带），缺失时回退 Consolas。
- 中文回退走系统字体，不打包中文字体（体积与许可）；PDF 中文字体由 Typst 从系统字体解析。
- 所有可点击文本禁止选中（`user-select: none`）；编辑区与预览页 canvas 例外（canvas 也禁止选中）。
- 全局 `-webkit-font-smoothing: antialiased`；正文 `text-rendering: optimizeLegibility`。

## 3. 布局

### 3.1 应用骨架

```
.app (display: grid; grid-template: 64px 1fr / 40px 1fr)
├─ .rail            (grid-area: 1 / 1 / 3 / 2)
├─ .topbar          (grid-area: 1 / 2)
└─ .main            (grid-area: 2 / 2; margin-top: 8px; border-top-left-radius: 6px)
   └─ .splitter
      ├─ .files-panel  (260px, 可折叠)
      ├─ .divider      (12px)
      ├─ .editor-pane  (1fr)
      ├─ .divider      (12px)
      └─ .preview-pane (42.63%)
```

- 应用底 `--layer-2`；rail 与 topbar 使用 `--layer-1`，`main` 区左上圆角 6，形成“白壳 + 灰底 + 白纸”的层次。
- 宽度 < 1100px 时：预览切换为可折叠（默认隐藏），编辑区占满；< 800px 时文件面板覆盖式抽屉（桌面最小窗口 960×600，正常不触发）。
- 浏览器/窗口没有底部状态栏；所有状态集中在 topbar 右侧与预览 toolbar。

### 3.3 topbar（40px）

- 结构：`8px 顶部留白 + 32px 内容`，三列 `1fr 2fr 1fr`，gap 8，左右 padding 8。
- 左列：返回（46×40 全高、贴齐窗口左上角，仅项目页显示，回到 Dashboard；图标为向左尖号 `ChevronLeft`，复用右上角窗口控制的 `ControlButton`，外观与最小化按钮一致）、菜单按钮（项目页：Deckle / File / Edit / View / Help；Dashboard：Deckle / Project / View / Help）。Dashboard 的 `Deckle` 仅作为字标，不可点击；`Project` 含新建空白项目、打开文件（.typ）…、打开文件夹…、从模板开始（二级菜单列出模板目录中的模板，随用户导入/删除动态变化）；`View` 含主题（亮色/暗色）、视图（网格/表格）、排序（名称/创建时间/更新时间）；`Help` 含新手教程、关于。项目页的 File 菜单含新建/打开/关闭项目、快速打开、设置；Edit 含撤销/重做/查找替换。
- 中列：面包屑，实时反映当前位置；Dashboard 页显示 `Dashboard`；项目页显示 `项目名 › 文件相对路径`，项目名前有列表文件夹图标，返回箭头承担回到 Dashboard 的职责（v0.1 校准：不再插入 `Dashboard` 段，避免单用户下多一层无意义层级）。单项 padding 4 6、圆角 4、hover shaded；分隔符为 `--text-secondary`；当前文件名 600；点击项目名回到项目根，点击目录在文件树中定位（P1）。
- 右列：项目页显示保存状态文本（仅 `saving`/`dirty`/`error` 时出现：保存中 / 未保存 / 保存失败）+ 窗口控制（仅 Windows/Linux）；不显示 Typst 版本、页数 pill（M2 校准，页数信息在 M3 预览 toolbar 内呈现）。Dashboard 不显示项目状态。macOS 隐藏窗口控制，左列预留 78px 给交通灯。
- 拖拽区：topbar 的空白容器 `-webkit-app-region: drag`；按钮、面包屑、pill 全部 `no-drag`。
- 双击空白 = 最大化/还原。
- 窗口控制按钮 46×40（与 topbar 等高），图标 14–15px 线条；hover `--action-secondary-hover`；关闭 hover `#c42b1c` + 白色图标。**[校准]** 与 Windows 11 原生按钮尺寸对齐；返回按钮复用同一 `ControlButton`，避免样式漂移。

文件类型图标：`.typ` 用自绘 “T” 菱形；`.bib` 书签；图片/PDF/其它用通用文件图标。不复制 typst 图标。

- **[校准] 2026-11-12 显示项目根目录行**：`buildRows` 首行插入 `{ name: project.config.name, path: root, kind: 'directory' }` 的 `isRoot` 行，子项 depth 从 1 起（paddingLeft 24），点击折叠/展开整棵树；`aria-level` 由 1 起。因根目录不是普通条目，F2 / Delete 与其右键菜单的「重命名 / 删除」均禁用（`deleteProjectEntry` 本来就拒绝删除项目根、`assertInside` 也拒绝重命名到项目外），右键的「新建文件 / 新建文件夹 / 导入文件… / 在资源管理器中显示」保持可用。根节点无子项时在其下方（缩进 24）显示「这个项目还没有文件 / 正在读取…」，根节点折叠时不显示；新建文件/文件夹与导入文件会自动展开目标目录，避免折叠态下误以为操作未生效。项目名跟随 `project.config.name`（未建 config 时为目录名），与窗口标题、面包屑一致。
- **[校准] 2026-11-12 全部折叠 / 全部展开**：头部在导入文件与更多之间增加一个**状态切换按钮**，不额外占两个位置。除根目录外只要还有展开的目录就显示「全部折叠文件夹」（`ChevronsDownUp`），否则显示「全部展开文件夹」（`ChevronsUpDown`）；加载期间显示 12px 进度圈并禁用，避免重复点击；项目里没有任何已知文件夹时「全部展开」也禁用（提示「项目中没有文件夹」）。**根目录在任何情况下都不收起**：全部折叠只把 `expanded` 重置为 `{ [root]: true }`。目录树是按需读取的，全部展开需逐层 `loadDir` 尚未加载的目录（同层并发、最多 64 轮、已尝试过的失败目录不重试），再一次性把可达目录全部置为展开；不可达的陈旧目录与符号链接环由 BFS + `seen` 集合排除。状态计算抽成 `renderer/lib/treeExpand.ts` 纯函数（`rootOnlyExpanded` / `allDirsExpanded` / `hasExpandedDir`），跨项目遗留的展开状态按路径归一化后忽略。
- **[校准] 2026-11-12 文件面板菜单与导入文件**：头部操作顺序固定为 新建文件 / 新建文件夹 / 导入文件 / 全部折叠·全部展开 / 更多（后加的按钮见上方校准），「更多」置于最右并使用 lucide 横向三点 `Ellipsis`；原先禁用的「更多」「导入文件（M4）」占位按钮启用。更多下拉菜单、文件树空白区右键菜单、行右键菜单共用「新建文件 / 新建文件夹 / 导入文件…」三项动作，目标目录依次为 当前文件所在目录、项目根、光标所在行（目录用自身、文件用父目录）；行右键菜单在分割线后保留 重命名 / 在资源管理器中显示 / 删除。导入走 `fs:importFiles`：主进程弹出系统多选文件对话框（不过滤类型，图片、`.typ`、PDF 等均可），用 `fs.copyFile` 按字节复制以保证二进制安全，同名自动追加 `-1/-2…` 后缀而不覆盖，跨项目目录与只读项目均拦截；完成后刷新目标目录并用 toast 汇总导入 / 自动改名 / 失败数量。设计稿把「导入」留到 M4 的占位说明已由本条校准取代。

Outline 面板（同一容器，标题 `Outline`）：

- 标题区：`=` 到 `======` 解析为层级，按 level 缩进（12px/级），行高 28；点击跳转到该行（0-based 行号 → 编辑器 1-based）。
- 图/表区：标题下方分“图 N”“表 N”两组（11/600 小标题 + 计数），每行 24px：lucide `Image`/`Table2` 16px 图标 + “图 1/表 1”编号 + 题注单行省略；点击同样跳转。
- 解析在渲染进程完成（`outlineModel.ts`）：屏蔽代码块、`#figure(` 括号配对、`caption: [...]` 支持嵌套方括号、`table(` 或 `kind: table` 判表；空态文案“当前文件没有标题、图或表”。

### 3.5 分隔条（12px）

- 宽 12，透明；hover 显示 1px `--action-primary` 居中线（`::after`），拖动时持续显示。
- 光标 `col-resize`；拖动时禁用 iframe/canvas 指针事件，避免丢帧。
- 双击复位为 `57.3746% / 42.6254%`；拖动范围：文件面板 200–480，编辑/预览各自 ≥ 320。
- 比例存 `workspace.json` 的 `split`（0–1，编辑区占比）。

### 3.6 编辑面板

- 顶部 toolbar：`padding: 0 0 12px`；M2 校准为无边框扁平排版，`gap: 2px`，高度 30。
- 工具按钮：30×30（Ag 34×30），hover `--action-secondary-hover`，disabled 时 opacity .9；M2 第二片已接入全部命令（粗体/斜体/下划线/标题/列表/有序/数学/代码/引用）。
- Ag 打开字体菜单（320 宽、最高 480）：顶部搜索框，下方为系统字体 + 内置字体（New Computer Modern / New Computer Modern Math / DejaVu Sans Mono）列表，每项用自身字体渲染；选择后若文档已有 `#set text(font: …)` 则替换整行，否则插入到文档开头，作为整篇正文字体。
- 工具顺序：字体（Ag）｜B / I / U｜H1｜无序列表 / 有序列表 / 数学（Σ）/ 代码块 / 引用（@）。不设评论、分享、账号入口。
- 编辑 sheet：`--layer-1`、`--effect-shadow-1`、上方圆角 6，`height: calc(100% - 12px)`，`margin-top: 12px`。
- CM6：填满 sheet；`.cm-scroller` padding 0；gutters 背景 `--layer-1`，右/左 1px `--border-secondary`；行号 padding 8；当前行背景变量；选区变量；光标 2px `--action-primary`；`tab-size: 2`；`.cm-line` padding `0 2px 0 6px`；内容底部留 40vh 空白。
- 折叠箭头 12px，圆角 chevron（`stroke-linecap: round`），默认 55% 不透明度、hover 100%；标题/代码块/列表/数学块可折叠。

### 3.7 预览面板

- toolbar：height 30，`padding: 0 0 12px`；**分三块**（左右各 `flex:1`、中间 `flex:none` 居中）：左侧为 护眼模式（`Leaf`）、适应宽度（`Maximize2`）两个可激活按钮；中间为缩放组（缩小 / 百分比 / 放大，min-width 4em）；右侧为编译状态（spinner、错误数、重试）+ 导出 PDF 下拉（仅 PDF）。不设 Share/发布入口。
- 预览容器：始终 `--layer-3`，护眼模式**不改背景色**，只换纸面色；`padding: 26px`、`gap: 26px`、列向 flex、上方圆角 6、`overflow: auto`、`scrollbar-gutter: stable`。
- 纸面：默认白色；护眼模式为豆沙绿（浅色 `#c7edcc`，夜间 `#b4d4b8` 压暗一档）。`--effect-shadow-page`、`margin-inline: auto`、宽 = `595.28 * 1.28 * zoom`，高按页面比例；页面之间 gap 26；M2 用同比例空占位，M3 换成渲染 canvas。canvas 的 `backgroundColor` 必须与纸面同色，否则护眼模式下仍是白底。
- 适应宽度：**可切换的自动模式**（`settings.preview.fitWidth`，默认开启）。仅激活时挂载 ResizeObserver，rAF 计算 `(容器宽 - 52) / (595.28 * 1.28)`，clamp 50%–200%，与当前 zoom 差 >0.005 才更新以免观察器循环；拖拽分隔条改变预览宽度即持续重算。手动缩放（按钮 / Ctrl+滚轮 / 百分比回 100%）会自动退出该模式，避免下一次尺寸变化把用户比例覆盖回去。
- canvas：CSS 尺寸 = 纸面尺寸；背板 = CSS × min(dpr, 2)；`user-select: none`；`image-rendering: auto`。
- 缩放：50%–400%，按钮步进 5%（实现值）/ Ctrl+滚轮连续；`transform: scale` 过渡 `.2s cubic-bezier(.95,-.01,.72,1.13)`；拖动滚动时禁用过渡。
- **[已接入] 2026-11-12 Ctrl/⌘+滚轮缩放**：监听挂在 `section[aria-label="预览"]` 上，覆盖 toolbar 与预览容器；必须用 `addEventListener('wheel', handler, { passive: false })`，因为 React 的 `onWheel` 是 passive，`preventDefault()` 无法阻止 Chromium 整页缩放。缩放按 `zoom *= exp(-deltaY * 0.0008)`（按 `deltaMode` 把行/页换算成像素），向上滚放大、向下滚缩小，clamp 50%–400%，与按钮共用 `MIN_ZOOM/MAX_ZOOM`（原来按钮被限在 200%，已放开到 400% 以免滚轮放到 300% 后点「放大」反而跳回 200%）；适应宽度仍 clamp 50%–200%。滚动前记录视口中心在文档中的相对位置，重建页面后按新 `scrollHeight` 还原，避免缩放跳页。主进程 `window.ts` 加 `zoom-changed` 兜底把 webContents 缩放级别复位为 0，防止整页跟着缩放。缩放仍复用现有 canvas 重渲染路径，连续捏合时会逐帧重建页面 div。
- 缩放百分比按钮点击 = 恢复 100%（同时退出适应宽度模式）；预设比例菜单（50/75/100/125/150/200/适应页面）为未实现的设想。
- **[校准] 2026-11-12 预览工具栏三分区 + 护眼模式**：原 toolbar 为「缩放组（含适应宽度）+ 状态 + spacer + 导出」的扁平排列，适应宽度是一次性按钮、用户夜间嫌白色 PDF 刺眼。现改为左/中/右三分区：左 护眼模式 + 适应宽度（两个 `aria-pressed` 可激活按钮），中 缩放组，右 状态 + 导出。护眼模式（新增 `settings.preview.eyeCare`，默认 false）按主题只给出纸面色 `{paper, ink}`，抽成 `views/previewTheme.ts` 纯函数；切换时因为 canvas 是用 `renderCanvas({ backgroundColor })` 画出来的，必须把纸面色加入渲染 effect 依赖触发重绘，同时同步页面 div / 空占位页。滚动区底色恒为 `--layer-3`、页码占位文字色恒定，二者不随护眼模式变化（用户反馈：只改纸张颜色即可）。适应宽度复用此前一直未使用的 `settings.preview.fitWidth`（默认 true），改为自动模式：仅激活时监听容器尺寸，拖拽分隔条持续重算；手动缩放一律先置 `manualRef` 再异步写设置，避免 IPC 往返期间被观察器覆盖。「适应宽度」从缩放组移除后，百分比按钮改为点击恢复 100%。缩放计算抽成 `fitZoomForWidth()` 纯函数。
- 空/错误态：居中 80px 图标（warning 色）、标题、说明、重试按钮；错误时顶部保留旧页。

### 3.8 菜单

- 容器：min-width 172，圆角 4，padding 4 0，`--layer-1`，`--effect-shadow-menu`，1px 透明边（阴影模拟）。
- 项：高 28，padding 0 12，13/400；hover `--action-secondary-shaded`；禁用 40% 透明；快捷键右对齐 11px `--text-secondary`；分隔线 1px `--border-modal`，margin 4 0。
- 子菜单箭头 12px；打开延迟 120ms，关闭 80ms；键盘：↑↓ 移动、→ 展开、← 收起、Enter 执行、Esc 关闭。
- 右键菜单同规格；文件树右键项：新建文件、新建文件夹、导入文件…、重命名、删除、在资源管理器中显示、复制路径（根目录行的重命名/删除禁用）。文件树键盘：F2 重命名，Delete 移入回收站（需确认）。
- **[校准] 2026-11-12 右键菜单改为非模态**：原实现用 MUI `Menu`（内部是 `Modal` + 全屏 `Backdrop`），菜单打开时右键落在遮罩上，文件树收不到 `contextmenu`，因此只能在左键点遮罩触发 `onClose` 时取消，无法在别处右键重新打开。现改为「更多」下拉与文件树右键菜单**共用一个菜单状态**，用 `Popper` + `Paper` + `MenuList` 渲染（无遮罩、portal 到 body、虚拟零尺寸锚点定位到鼠标）；视觉参数沿用主题里 `MuiMenu.paper` 的规格（min-width 172、圆角 4、`--effect-shadow-menu`、1px `--border-modal`），`MenuItem` 仍走 `MuiMenuItem` 主题覆盖。事件规则：① 菜单打开时右键点击树内任意位置 → 由树容器的 `onContextMenu` 按 `closest('[data-tree-row]')` 解析目标行，直接把菜单换成新位置、新目标目录；② 左/中键点击菜单与触发按钮之外 → 关闭（右键的 `pointerdown` 特意不关闭，留给随后的 `contextmenu` 重定位）；③ 右键点在菜单自身 → 只 `preventDefault()` 屏蔽浏览器原生菜单并保持；④ 右键点在树外 → 关闭且不干扰该区域自身右键；⑤ Esc、窗口失焦/缩放、树滚动 → 关闭。关闭判定抽成 `renderer/lib/contextMenu.ts` 纯函数（`closeOnPointerDown` / `closeOnContextMenu` / `contextTargetDir` / `anchorRectAt`）。

- **[校准] 项目卡与 Dashboard 按钮、模板列表同视觉语言**：容器 1px `--border-secondary` 边框、无阴影、`cursor: pointer`；hover 与 `.template-row:hover` 同源——`background-color` 以 120ms ease 变为 `--action-secondary-hover`，边框不再单独加深。因封面缩略图铺满卡片，底色变化会被盖住，故用 `::before` 叠一层同色半透明层（`opacity: 0 → 0.55`，120ms ease）把变化显出来并保留封面可见；该层 `z-index: 1`，首字同为 1、悬浮按钮组为 2，保证按钮 hover 不被削弱。focus-visible 为 2px `--border-focus` 内描边（`outline-offset: -2px`，等效按钮 inset 焦点环且不被封面覆盖）；暗色不再用硬编码半透明白边。卡内四个按钮复用 `.dashboard-icon-btn` + `.template-action`（删除项另加 `.template-action-danger`），hover / focus / danger 与模板列表按钮完全同源，颜色全走主题变量；隐藏态用 `pointer-events: none`，靠 `:focus-within` 保证键盘可达。原因：卡片原先的阴影 hover、外描边焦点环、硬编码色值，以及首轮校准的「只变边框不变底色」，都与按钮/模板列表的「进入即变色」割裂。
- **[校准] 2026-11-12 移除蓝色渐变与右上角折角**：`.project-card` 原 `background-image: linear-gradient(325.34deg, #007aff, #7fc9ff)` 与 `::after` 折角 `#ffffffb3` 来自 2026-11-10 照搬 typst.app 保存页的视觉，实际上只是封面缩略图加载中/失败时的回退占位，成功时会被铺满的白纸封面完全盖住。因与扁平的按钮/模板行语言冲突，两者均已删除；容器改 `align-items/justify-content: center` 让回退首字居中，`color` 由白色改 `--text-primary`，首字改 40px/600 `--text-secondary` + 50% 透明度。hover 逻辑不变：无封面时 `background-color` 直接变为 `--action-secondary-hover`（与 `.template-row` 一致），有封面时由 `::before` 半透明层显出变化。原因：渐变是回退态而非主视觉，去掉后亮/暗主题都走主题变量，且不影响缩略图成功时的呈现；`04-roadmap.md` 中「渐变卡与折角」为 2026-11-10 历史记录，保留不改。
- **[修复] 2026-11-12 模板行在数量多时被压扁**：`.template-row` 是 `[data-template-list]`（纵向 flex，`flex:1; min-height:0; overflow-y:auto`）的子项，原先只声明 `height: 56px` 而未锁定收缩；自身 `overflow: hidden` 又使 flex item 的自动最小高度变成 0，于是模板 ≥12 个时行高被压到 19px，40 个以上只剩 2px（仅上下边框），文字与四个操作按钮被裁掉；12 个时压缩后总高恰好等于可视高度，连滚动条都不出现。修复为在 `.template-row` 加 `flex-shrink: 0`，行高恒定 56px。验证：隐藏 Electron 窗口加载真实 `tokens.css` + 复刻 Dashboard DOM，4 种窗口尺寸 × 6 组项目/模板数量 × 2 种名称长度 × 产品/回归两种变体共 96 组；产品 CSS 的 48 组失败 0（行高恒 56px、卡片恒 230px、页面/Dashboard/项目区/模板清单横纵均无溢出、模板清单滚动正常、长名称 ellipsis 生效），人为 inline 覆盖 `flex-shrink:1` 的对照组仍有 24 组失败（行高 19px / 2px 复现），证明用例具备鉴别力。项目网格侧原本就正常，未改动。
- 列表视图：行高 40，名称 1fr / 更新时间 120px / 箭头 24px。
- 模板项：名称 13/600 + 描述 11px 次要色，hover 时右侧出现四个 40px 图标按钮——“从模板开始”（Play，复制模板到新项目，不修改模板本身）、“预览模板”（Eye，只读打开）、“更改模板”（Pencil，以项目方式打开模板目录直接编辑 main.typ）、“删除模板”（Trash2，二次确认）。
- 模板存储于 `%APPDATA%\Deckle\templates\<id>\{template.json,main.typ,...}`；首次运行播种论文模板、课程论文、实验报告、空白项目四个内置模板，用户删除后不再复活；导入支持 `.typ` 文件或含 `main.typ`（或根目录唯一 `.typ`）的文件夹。
- 空态：虚线框内居中文件夹图标、标题“还没有项目/没有匹配的项目”、说明（搜索时提示换关键词）。
- 右侧 aside：300px，三个 1px 边框链接行（Typst 文档 / 包与模板 / 快捷键与帮助），点击用系统浏览器打开 typst.app（主进程校验 https + 域名白名单）；下方“关于”说明单机单用户与图标来源。
- 设置入口：rail 的“应用设置”打开应用级设置（外观/文件/关于）；项目级设置不在此页出现。

## 7. 无障碍

- 所有图标按钮有 `aria-label`；菜单 `role="menu"`、项 `role="menuitem"`；文件树 `role="tree"`、行 `role="treeitem"`，`aria-level/expanded/selected`。
- 焦点环：2px `--action-primary`，`outline-offset: 2px`；不以颜色作为唯一状态（脏点、错误图标同时存在）。
- 对比度：正文与背景 ≥ 4.5:1；大字号 ≥ 3:1；暗色主题逐一校验。
- 键盘可达：Tab 顺序 rail → topbar → 面板 → 编辑区 → 预览；Esc 关闭浮层；F6 在面板间循环（P1）。
- 屏幕阅读器：状态变化通过 `aria-live="polite"` 播报（保存、编译完成、错误数）。

## 8. 视觉验收与校准

1. M1 首日：用同一份 A4 示例文档，截图对比 typst.app 项目页（用户提供或自截），重点核对 topbar 高度、rail 图标位置、文件行高、sheet 圆角/阴影、预览 gap。
2. 像素容差：结构尺寸 ±2px；颜色以本文变量为准，允许 ±3 色阶。
3. 每轮 UI 改动后在 `docs/design/02-ui.md` 记录偏差与原因；变量改动必须同步 `tokens.css` 与本文件表格。
4. 不追求逐像素复制：字体渲染、窗口 chrome、滚动条因平台而异，以“同一视觉语言”为准。
