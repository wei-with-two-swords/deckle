  and a different icon**, with a clear note such as “based on Deckle”.

## Forks / 分支

If you distribute a modified version, please:

1. Choose a different product name and replace the icon;
2. Change the application id / bundle id and installer name so it can coexist
   with the official app;
3. Keep the Apache-2.0 `LICENSE` and `NOTICE` files, and state prominently
   what you changed;
4. Link back to this repository as the origin, without implying endorsement.

分发修改版时请：

1. 使用不同的产品名称并替换图标；
2. 修改 application id / bundle id 与安装包名称，使其可与官方版共存；
3. 保留 Apache-2.0 的 `LICENSE` 与 `NOTICE`，并显著说明你的修改；
4. 注明本项目为来源，但不要暗示获得背书。
