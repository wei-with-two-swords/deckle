# Privacy Policy / 隐私政策

Last updated / 最后更新：2026-11-17

## English

Deckle is a local-first desktop application. It does not require an account
and does not include telemetry, analytics, advertising or crash reporting.
We do not collect, transmit, sell or share personal data.

**Where your data lives.** Documents, projects, settings, recent-project
records and recovery snapshots are stored only on your computer — in the
folder you chose for each project and in `%APPDATA%\Deckle`. The app reads and
writes these files to provide editing, preview, recovery and export. You can
delete them at any time; uninstalling keeps them unless you remove that folder
yourself.

**Network access.** The current 1.0 release performs editing, compilation,
preview and PDF export entirely offline and does not contact any server on its
own. There is no licence activation, no update check and no remote font or
template service. If you choose a link that opens an external site, that
request is handled by your browser, not by Deckle. If a future release adds an
optional online feature, this policy will be updated and the feature will be
opt-in where required.

**Third-party sites.** Downloading a release from GitHub is subject to
GitHub's own privacy policy. Deckle itself does not contact GitHub.

**Children.** Deckle is a general-purpose writing tool and is not directed at
children under 16. We do not knowingly collect data from anyone.

**Changes and contact.** Material changes will be noted in this file and in
release notes. Questions: `shuangjian_wei@163.com`.

## 简体中文

Deckle 是一款本地优先的桌面应用，不需要账号，也不包含遥测、统计分析、
广告或崩溃上报。我们不收集、不传输、不出售、不共享个人数据。

**数据存放位置。** 文档、项目、设置、最近项目记录与恢复快照只保存在你的
电脑上：项目文件位于你选择的文件夹，应用数据位于 `%APPDATA%\Deckle`。
应用读写这些文件仅用于编辑、预览、恢复与导出。你可以随时删除它们；
卸载应用默认会保留这些数据，除非你自行删除该目录。

**网络访问。** 当前 1.0 版本的编辑、编译、预览与 PDF 导出全部离线完成，
不会自行连接任何服务器；没有授权激活、更新检查，也没有远程字体或模板服务。
如果你主动打开外部链接，该请求由浏览器处理，而不是由 Deckle 发起。
如果未来版本加入可选的在线功能，我们会更新本政策，并在需要时提供明确的
选择开关。

**第三方网站。** 从 GitHub 下载发行版时适用 GitHub 自己的隐私政策；
Deckle 本身不会连接 GitHub。

**儿童。** Deckle 是通用写作工具，不面向 16 岁以下儿童，我们不会明知而
收集任何人的数据。

**变更与联系。** 重大变更会记录在本文件与发行说明中。如有疑问，请联系
`shuangjian_wei@163.com`。
